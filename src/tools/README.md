# tools

CLI utilities for the port. Planned (M7+):

- `verify-assets` — checks that the user-provided assets tree is complete and
  well-formed (structure/signatures only; never inspects or redistributes
  copyrighted content).
- `dump-gx` — serializes the current GX state machine to JSON (debugging aid,
  tied to `compat/gx`).

Nothing here yet (M1 scope is the build system and platform core).
